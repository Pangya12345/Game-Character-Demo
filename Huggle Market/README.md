# ตลาดต่อราคา · Haggle Market

เกม 2D Pixel Art แนวเจรจาต่อรองราคา: ต่อราคามะม่วงกับ **แม่ค้าสมศรี** แม่ค้า AI ปากร้ายใจดีที่คิดและตอบตามสิ่งที่ผู้เล่นพูดจริง ๆ เล่นได้ทั้งโหมด **English** และ **ภาษาไทย** พิมพ์หรือพูดผ่านไมโครโฟนก็ได้

🎮 เล่นได้ที่ **https://haggle-market.vercel.app**

- **Frontend:** HTML/CSS/JS ล้วน ฉากตลาดและตัวละครวาดด้วย canvas ความละเอียด 320×180 แล้วขยายแบบพิกเซลคม ๆ เต็มจอ รองรับมือถือ
- **Backend:** Node.js เรียกใช้ Gemini API (หรือ Anthropic Claude API)
- **Offline demo mode:** ถ้าไม่มี API key หรือ AI ไม่ตอบ แม่ค้าจะใช้คำตอบสำรองแบบสคริปต์ เกมจึงไม่ค้าง

## วิธีรันบนเครื่อง

โค้ดทั้งหมดอยู่ในโฟลเดอร์ `Huggle Market`

```bash
cd "Huggle Market"
npm install
cp .env.example .env      # แล้วใส่ GEMINI_API_KEY (หรือ ANTHROPIC_API_KEY)
npm run dev               # เปิด http://localhost:3000
npm test                  # รันชุดทดสอบ edge case (ไม่ต้องใช้ API key)
```

| ตัวแปร | ความหมาย |
|---|---|
| `LLM_PROVIDER` | `gemini`, `anthropic` หรือ `offline` (เว้นว่างได้ ระบบจะเลือกตาม key ที่มี) |
| `GEMINI_API_KEY` / `GEMINI_MODEL` | key และโมเดลของ Gemini (ค่าเริ่มต้น `gemini-3.5-flash-lite`) |
| `GEMINI_FALLBACK_MODEL` | โมเดลสำรอง ถ้าโมเดลหลักตอบช้าเกิน 2.5 วินาที จะถามตัวนี้พร้อมกัน แล้วใช้คำตอบที่มาก่อน |
| `ANTHROPIC_API_KEY` / `ANTHROPIC_MODEL` | key และโมเดลของ Claude (ค่าเริ่มต้น `claude-sonnet-5`) |
| `FLOOR_PRICE` | ราคาต่ำสุดที่แม่ค้ายอมขาย เป็นความลับ (ค่าเริ่มต้น 80) |
| `IDLE_SECONDS` | ทุกกี่วินาทีที่ผู้เล่นเงียบ แม่ค้าจะทำอะไรสักอย่าง (25) |

ตั้ง `DEBUG_THOUGHTS=1` เพื่อดู "ความคิดในใจ" ของแม่ค้าใน console ของ server มีประโยชน์ตอนปรับ prompt

## วิธีเล่น

- **เลือกภาษา:** หน้าแรกเลือก English หรือภาษาไทย แล้วจะมีหน้าอธิบายกติกาก่อนเริ่ม ต้องพิมพ์หรือพูดภาษาที่เลือกเท่านั้น ถ้าใช้ภาษาอื่นแม่ค้าจะงง (ไม่รู้ว่าเป็นภาษาอะไร) และถ้าทำบ่อยจะโกรธ
- **ภารกิจงบจำกัด:** ทุกเกมจะสุ่มงบและจำนวนที่ต้องซื้อ เช่น "มีเงิน 300฿ ต้องซื้อ 3 กก." ใต้ราคาจะแสดงยอดรวม (สีแดง = เกินงบ, สีเขียว = อยู่ในงบ) แม่ค้าไม่รู้ว่าผู้เล่นมีเงินเท่าไร นอกจากผู้เล่นจะบอกเอง ตั้งค่าภารกิจได้ที่ `MISSIONS` ใน `public/js/game.js`
- **พิมพ์หรือพูด:** กดปุ่มไมค์ 🎤 แล้วพูด คำจะขึ้นในช่องแชทแบบสด ๆ ไมค์ปิดเองเมื่อหยุดพูดประมาณ 1 วินาที แล้วกด Enter หรือ SEND เพื่อส่ง (ไม่ส่งเอง จะได้แก้คำที่ฟังผิดก่อน) ใช้ระบบฟังเสียงของเบราว์เซอร์ (Chrome, Edge, Safari) ไม่ต้องใช้ API key เพิ่ม
- **ต่อราคา:** เริ่มที่ 120 บาท/กก. ความสุภาพ เหตุผลที่น่าเชื่อ การซื้อหลายกิโล การชวนคุย และเทคนิคต่อรอง ช่วยให้ได้ส่วนลด ส่วนการต่อต่ำเกินเหตุ การกดดัน หรือ "deal" ปลอม ๆ จะไม่ได้ลด
- **การตกลงซื้อ:** แม่ค้ายอมราคาแล้ว**ยังไม่ถือว่าซื้อ** ผู้เล่นต้องยืนยันเอง เช่น "ตกลง", "เอาเลย", "deal", "I'll take it" ถ้ายังไม่ยืนยันก็ต่อราคาต่อได้
- **ความอดทนของแม่ค้า (0–100):**
  - **ลดลง:** ตอนเงียบ (ระหว่างกำลังพิมพ์ลดช้าลงประมาณ 3 เท่า), ตอนต่อต่ำเกินเหตุ, ถามซ้ำ, พูดไม่ดี หรือพูดผิดภาษา
  - **เพิ่มขึ้น:** ตอนพูดสุภาพ ให้เหตุผลดี หรือชวนคุยถูกใจ
  - **หยุดนับ:** ตอนแม่ค้ากำลังพูด และตอนผู้เล่นกำลังพูดผ่านไมค์
  - AI ประเมินทุกข้อความ ส่วน server บังคับกติกาหลักให้ยุติธรรม
- **เงียบนาน:** ทุก 25 วินาที แม่ค้าจะสุ่มทำอะไรสักอย่างตามความอดทนที่เหลือ เช่น ชวนคุย, ทำอย่างอื่นรอ, เสนอของแถม, ลดให้ 2–3 บาทถ้าตัดสินใจเลย (ครั้งเดียวต่อเกม), บ่นแล้วขึ้นราคา 5 บาท หรือเริ่มเก็บของ
- **ดีลล่มเมื่อ:**
  - ความอดทนหมด (ตอนจบสุ่มได้หลายแบบ เช่น ไล่, เก็บร้าน, คุยโทรศัพท์กับหลาน, "พรุ่งนี้มาใหม่")
  - ด่าหรือพูดหยาบคาย (จบทันที)
  - ถามคำเดิมซ้ำจนเกินรอบที่ 5–7 (สุ่มต่อเกม)
  - ตกลงราคาแล้วแต่เงินไม่พอจ่าย
- **ปุ่มบนจอ:** HINT (คำใบ้), RESTART (เริ่มเกมใหม่ด้วยภารกิจใหม่), MENU (กลับหน้าแรก)

## ระบบ AI

ทุกครั้งที่ผู้เล่นส่งข้อความ server จะส่งข้อมูลต่อไปนี้ให้ LLM:
- บุคลิกของแม่ค้า
- สถานการณ์ของวันนั้น (สุ่มต่อเกม)
- กติกาการขายแบบตลาดจริง
- บทสนทนาที่ผ่านมา (สูงสุด 40 ข้อความ)
- ราคาปัจจุบันและความอดทนที่เหลือ

LLM จะคิดใน `inner_thoughts` ก่อน แล้วจึงตอบ ฟิลด์นี้ server จะตัดทิ้ง ไม่ส่งไปถึงผู้เล่น

ข้อมูลที่หน้าเว็บได้รับเป็น JSON ตาม spec และมีฟิลด์เสริมอีก 3 ตัว:
- `patience`: ความอดทนใหม่หลังข้อความนี้
- `end_reason`: สาเหตุที่ดีลล่ม (มีเฉพาะตอนดีลล่ม)
- `mode`: บอกว่าคำตอบมาจาก AI ตัวไหน

```json
{
  "detected_language": "th",
  "npc_response": "ร้อยห้าก็ร้อยห้า เอาไปสามโลนะ ตกลงราคานี้เลยไหมจ๊ะ",
  "npc_mood": "happy",
  "current_price": 105,
  "deal_closed": false,
  "deal_failed": false,
  "patience": 92,
  "mode": "gemini"
}
```

**Server ไม่เชื่อ AI ทั้งหมด ตรวจซ้ำทุกครั้ง** (อยู่ใน `backend/negotiate.js` และ `backend/rules.js`):
- **ราคา:** ไม่ต่ำกว่า `FLOOR_PRICE` และไม่ต่ำกว่าราคาที่ผู้เล่นขอ ขึ้นได้ไม่เกิน 5 บาท และเฉพาะตอนแม่ค้าโกรธจริง ๆ
- **การตกลงซื้อ:** จะปิดดีลได้ก็ต่อเมื่อผู้เล่นยืนยันจริง ถ้าเป็นคำปฏิเสธ คำถาม หรือข้อเสนอที่ต่ำกว่า จะไม่นับว่าตกลง
- **ถามซ้ำ:** server นับเองว่าข้อความซ้ำกับครั้งก่อนไหม
- **ภาษา:** บังคับตามโหมดที่ผู้เล่นเลือก
- **ข้อความของแม่ค้า:** ตัวเลขราคาในประโยคจะถูกแก้ให้ตรงกับราคาบนจอเสมอ

**ความเร็วในการตอบ:** Gemini ฟรีบางครั้งตอบช้า server จึงถามโมเดลหลักก่อน ถ้าเกิน 2.5 วินาทีจะถามโมเดลสำรองพร้อมกัน แล้วใช้คำตอบที่มาก่อน ถ้าเกิน 9 วินาทีจะใช้คำตอบสำรองแทน

## Deploy (ได้ลิงก์ไปส่งให้เพื่อนเล่น)

### Vercel (ที่ใช้อยู่ตอนนี้)
- **deploy ใหม่หลังแก้โค้ด:** รันคำสั่งนี้จากในโฟลเดอร์ `Huggle Market`
  ```bash
  npx vercel deploy --prod
  ```
- **สร้างโปรเจกต์ใหม่จากหน้าเว็บ Vercel:**
  - import repo นี้ แล้วตั้ง **Root Directory = `Huggle Market`**
  - Framework Preset เลือก **Other**
  - ใส่ `GEMINI_API_KEY` ใน Environment Variables
- **บน Vercel:** ไฟล์ใน `public/` จะเสิร์ฟเป็นหน้าเว็บ ส่วน `api/*.js` จะรันเป็น serverless function ที่เรียกใช้โค้ดใน `backend/`

### Render (ทางเลือก)
1. สร้าง **Web Service** จาก repo นี้
2. ตั้ง **Root Directory = `Huggle Market`**, Build = `npm install`, Start = `npm start` (ค่าอื่นดูได้จาก `render.yaml`)
3. ใส่ `GEMINI_API_KEY` ใน Environment

> อย่า commit ไฟล์ `.env` เด็ดขาด ไฟล์นี้อยู่ใน `.gitignore` แล้ว ให้ใส่ key ในหน้า dashboard ของ Vercel หรือ Render เท่านั้น

## โครงสร้างโปรเจกต์

```
Huggle Market/
├── api/                 # Vercel serverless functions
│   ├── negotiate.js     #   POST /api/negotiate
│   └── config.js        #   GET  /api/config
├── backend/
│   ├── server.js        # Express server (รันบนเครื่อง / Render)
│   ├── negotiate.js     # ตรวจ input/output, ราคา, ความอดทน, ถามซ้ำ, rate limit
│   ├── rules.js         # กติกากลาง: ล็อกภาษา, อ่านราคาที่เสนอ, การยืนยันซื้อ
│   ├── llm.js           # เรียก Gemini (ถาม 2 โมเดลพร้อมกัน) / Claude
│   ├── prompt.js        # บุคลิก กติกา และฉากของแม่ค้าสมศรี
│   ├── offline.js       # คำตอบสำรองแบบ rule-based
│   └── config.js
├── public/
│   ├── index.html
│   ├── css/style.css
│   └── js/
│       ├── game.js      # state, ความอดทน, ไมค์, UI 2 ภาษา, หน้ากติกา/ผลลัพธ์
│       ├── scene.js     # pixel art: ฉากตลาด, sprite, สีหน้าตามอารมณ์
│       └── audio.js     # เสียง chiptune ด้วย WebAudio
├── test/rules.test.mjs  # ชุดทดสอบ edge case (npm test)
├── .env.example
├── vercel.json
└── render.yaml
```
